# Complaint Management System (CMS)

A responsive Complaint Management System web application built using HTML5, CSS3, and JavaScript with LocalStorage data handling.

## 🚀 Live Demo
[View Live Website](https://ksubhojit14-droid.github.io/CMS-Project/)

## ✨ Key Features
- **User Authentication:** User Registration and Login.
- **Complaint Management:** Submit complaints and view complaint status/history.
- **Responsive Design:** User-friendly UI for both Desktop and Mobile.

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript
